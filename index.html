Benefits of Cloud Computing

Cost Effective

Reduce hardware costs and pay for the resources you need.

Scalability

Increase or decrease computing resources as needed.

Accessibility

Access applications and data through the internet.

Cloud Service Models

IaaS

Infrastructure as a Service provides virtual computing resources.

PaaS

Platform as a Service provides tools to develop applications.

SaaS

Software as a Service provides applications over the internet.
